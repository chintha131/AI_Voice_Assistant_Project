# AI_Voice_Assistant_Project

Simple, mobile-friendly birthday wish website for Ma'am.

## Run locally (correct way)
Do **not** paste CSS/HTML into the terminal.

```bash
cd /workspace/AI_Voice_Assistant_Project
python -m http.server 5500
```

Then open:

- `http://localhost:5500/index.html`

## One-command launcher

```bash
bash run.sh
```

This starts a local server on port `5500`.

## Required final asset
The page expects this file:

- `assets/maam-appreciation.mp4` (30–60 seconds, recommended 45s)

Subtitles are already wired via:

- `assets/maam-appreciation.vtt`
